> 💡 **핵심** — 그로기는 종류 상관없이 **15초 유지, 딜 2배!** 그로기 타이밍에 몰아서 때리기.

## 진행 순서

**1번방 → 2번방 → 이루샤 (중간 보스) → 최종결전 → 완성형 글라스 기브넨 (최종 보스)**

---

## 중간 보스: 이루샤

### 체력별 패턴

| 체력 | 패턴 |
| --- | --- |
| 90% | 솥 |
| 75% | 타수 |
| 65% | 솥 |
| 50% | 타수 |
| 25% | 타수 |
| 15% | 솥 |

### 이루샤의 장난
- 15초마다 몬스터 1종 랜덤 소환
- 6마리가 되면 5초간 강제 변신
- 특수 패턴(솥·타수)이 시작되면 장난은 멈춤

### 마법 솥 패턴
- 45초 안에 **12시 방향 마법 솥**을 눌러서 게이지를 전부 채우기
- 게이지 가득 채우는 데 7초
- 넘어지면 게이지 초기화 → **굳건, 실드** 써서 버티기
- 솥 패턴 45초 동안이 **극딜 타이밍**

### 타수 패턴
- 좌우좌우 광클해서 속박 풀기
- 요구하는 타수 채우기
- **프렌지 & 봉제인형 파트너** 또는 **모모** 있으면 편함

## 최종 보스: 완성형 글라스 기브넨

### 체력별 패턴

| 체력 | 패턴 |
| --- | --- |
| 90~80% | 쉬리커 |
| 80% | 구슬 |
| 75% | 잡몹 |
| 70% | 추종자 |
| 65% | 잡몹 |
| 60~50% | 쉬리커 |
| 45% | 잡몹 |
| 40~30% | 쉬리커 |
| 35% | 추종자 |
| 30% | 구슬 |
| 25% | 잡몹 |

### 쉬리커 소환
- 맵 가장자리에서 자폭 쉬리커가 잔뜩 나옴
- 쉬리커 **2마리를 보스에게 터뜨리면** 보스 그로기

### 심연의 구슬 패턴
- 맵에 생기는 **구슬 4개 파괴**
- 성공하면 보스 그로기

### 잡몹 소환 패턴
- 맵 가운데에 잡몹이 랜덤으로 잔뜩 나옴
- **카리의 장판**이 보스에게 닿으면 보스 데미지 감소

### 추종자 패턴 ⚠️
- 맵 가장자리 4방향에 추종자 소환
- **Z 모양 순서대로 잡기**: 1번(왼쪽 위) → 2번(오른쪽 위) → 3번(왼쪽 아래) → 4번(오른쪽 아래)
- 성공하면 보스 그로기
- **실패하면 전원 즉사!**

---

## 그로기 정리

- 쉬리커 / 구슬 / 추종자 성공 → 보스 그로기
- 그로기는 종류 상관없이 **15초 유지, 딜 2배**
